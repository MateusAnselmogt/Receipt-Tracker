# Receipt Tracker

A web application built with HTML, CSS, and JavaScript that allows users to upload receipt images and extract information from them using AI through Puter.js.

## Features

* Upload receipt images
* Extract receipt information using AI
* Display extracted data on the page
* Add multiple receipts
* Calculate the total amount from all added receipts

## Technologies

* HTML
* CSS
* JavaScript
* Puter.js

## How It Works

The user uploads an image of a receipt through the application. The receipt is processed using AI through Puter.js, and the extracted information is displayed on the page.

Multiple receipts can be added, allowing the application to calculate the combined total amount.
